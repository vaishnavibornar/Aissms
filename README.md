# 🌱 GreenPoints (Frontend Demo)

> **Build a Cleaner Future, Together.**
> A modern environmental reporting platform interface designed to empower citizens and administrators.

![GreenPoints Banner](src/assets/banner-placeholder.png)

## 📖 About
GreenPoints is a React-based web application that demonstrates a modern interface for civic engagement. It simulates the experience of reporting environmental hazards, tracking locations, and managing community issues.

**Note:** This is a **Frontend-Only Demo**. It uses browser `localStorage` to simulate a database and data persistence, allowing users to experience the full UI/UX flow without requiring a backend server.

## ✨ Key Features (Demo Mode)

### 👤 Citizen Interface
- **📸 Camera Simulation:** Demonstrates camera access and image capture workflow.
- **📍 Location Tagging:** Fetches real browser geolocation coordinates.
- **✨ Glassmorphism UI:** Premium, modern aesthetic with frosted glass effects.
- **🗳️ Interactive Feed:** Simulates upvoting and community engagement.

### 🛡️ Administrator Interface
- **📊 Dashboard UI:** Visualizes data organization and management tools.
- **✅ Resolution Workflow:** Demonstrates how admins would approve or reject complaints.

## 🛠️ Tech Stack

- **Frontend:** React.js (Vite)
- **Styling:** Custom CSS3 (Glassmorphism, Animations)
- **Routing:** React Router DOM
- **State Management:** React Context API
- **Data Persistence:** LocalStorage (Mock Database)
